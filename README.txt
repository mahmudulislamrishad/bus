BANGLADESH BUS SIMULATOR — PHASE 1 PROTOTYPE

Files:
- index.html
- style.css
- src/main.js

Run:
This uses a Three.js ES module from CDN, so run it through a web server (not file://).
You can upload these files to GitHub Pages, or run locally with a simple server:
  python -m http.server 8000
Then visit http://localhost:8000

Controls:
Touch: Left/Right, ACCEL, BRAKE, REV, CAMERA, HORN
Keyboard: Arrow keys or WASD

Prototype notes:
This is an initial procedural 3D playable prototype. The bus model, environment, physics and traffic are placeholders for future upgrades. It is not yet a realistic simulator.
